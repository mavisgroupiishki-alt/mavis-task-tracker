# MAVIS Task Tracker 6.2.7 — стабильная расшифровка встреч

Исправление ошибки `Не удалось расшифровать часть N: Failed to fetch`.

Что изменено:
- встреча делится на фрагменты по 10 минут вместо 15;
- фрагменты отправляются на расшифровку последовательно, а не параллельно;
- при временной сетевой ошибке / 429 / 5xx выполняется до 3 попыток;
- если все попытки неудачны, аудиофрагмент сохраняется в памяти текущей вкладки;
- для неудачного фрагмента есть кнопки «Повторить» и «Пропустить»;
- анализ встречи нельзя запустить случайно, пока есть неразобранный ошибочный фрагмент;
- исправлена нумерация частей при пропусках;
- SQL не требуется.

## Обновление
1. Распакуйте архив 6.2.7.
2. Замените файлы в GitHub-репозитории MAVIS Task Tracker содержимым архива.
3. Дождитесь Render Deploy = Live.
4. Обновите приложение через Cmd+Shift+R / Ctrl+Shift+R.

## Важно
Не обновляйте страницу во время записи встречи: резерв неудачного аудиофрагмента хранится в памяти вкладки до успешной расшифровки или закрытия/обновления страницы.
