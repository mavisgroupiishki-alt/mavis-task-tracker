# Версия 6.2

- Добавлен серверный прокси Bitrix24 Вайбкод AI.
- API-ключ хранится только в `VIBECODE_API_KEY` на Render.
- Добавлена вкладка «ИИ-помощник».
- Добавлена голосовая постановка одной задачи.
- Добавлена запись встречи РНП с автоматическим делением на 15-минутные части.
- Добавлена расшифровка аудио через `/v1/audio/transcriptions`.
- Добавлено структурирование задач через `/v1/chat/completions`.
- Добавлен экран ручного подтверждения и редактирования задач.
- ИИ использует только существующие разделы, проекты, этапы и сотрудников.
- Сохранено отображение задач проекта без этапа.
