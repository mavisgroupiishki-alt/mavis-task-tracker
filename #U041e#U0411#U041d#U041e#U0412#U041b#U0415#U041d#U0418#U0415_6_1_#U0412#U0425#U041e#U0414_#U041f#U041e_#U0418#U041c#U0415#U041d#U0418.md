# MAVIS Task Tracker 6.1 — Аня с паролем, сотрудники по выбору имени

## Как теперь устроен вход

- Аня входит как администратор по паролю.
- Остальные сотрудники выбирают своё имя на стартовом экране. Пароль им не нужен.
- Выбранное имя запоминается в браузере. Для смены сотрудника нужно нажать «Выйти».
- Только Аня может создавать и редактировать разделы, добавлять и отключать сотрудников, менять должность, имя, цвет и норму загрузки.

> Важно: вход сотрудника без пароля — это удобная идентификация, а не строгая защита личности. Человек, у которого есть ссылка на приложение, технически может выбрать чужое имя. Административные действия при этом всё равно защищены паролем Ани и политиками Supabase.

## Шаг 1. Создать пароль Ани в Supabase

В Supabase откройте:

**Authentication → Users → Add user**

Укажите:

- Email: `anya@mavis.local`
- Password: личный пароль Ани, не короче 8 символов
- Auto Confirm User: включить

Если пользователь `anya@mavis.local` уже создан, повторно создавать его не нужно.

## Шаг 2. Исправить доступ к базе

Откройте:

**Supabase → SQL Editor → New query**

Скопируйте целиком файл:

`supabase_v6_1_admin_and_employee_choice.sql`

Нажмите **Run**.

В результате должны появиться значения:

- `employee_choice_ready = true`
- `tasks_access_ready = true`
- `anya_employee_ready = true`

Этот SQL исправляет ошибку:

`permission denied for table tasks`

Он не удаляет проекты, задачи, этапы, разделы и историю.

## Шаг 3. Обновить GitHub

1. Распакуйте ZIP версии 6.1.
2. Откройте правильный репозиторий приложения.
3. Загрузите содержимое распакованной папки прямо в корень репозитория.
4. Замените старые файлы.
5. Нажмите **Commit changes**.

В корне должны находиться `package.json`, `index.html`, `render.yaml` и папка `src`.

## Шаг 4. Обновить Render

1. Render → сервис приложения → Deploys.
2. Нажмите **Manual Deploy → Deploy latest commit**.
3. Дождитесь статуса **Live**.
4. В браузере нажмите `Cmd + Shift + R`.

В шапке приложения должна быть версия **6.1**.

## Первый вход

### Аня

На правой карточке «Вход Ани» вводит пароль от пользователя `anya@mavis.local`.

### Сотрудник

Нажимает на карточку со своим именем. Пароль не вводит.

## Добавление сотрудника

Аня открывает вкладку **Команда → Добавить** и указывает:

- имя;
- должность;
- норму активных задач;
- цвет;
- показывать сотрудника на экране входа или отключить.

Логин и пароль для сотрудника создавать не нужно.
