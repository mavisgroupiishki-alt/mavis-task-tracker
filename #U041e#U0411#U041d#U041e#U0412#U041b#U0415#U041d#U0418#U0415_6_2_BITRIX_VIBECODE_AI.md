# MAVIS Task Tracker 6.2 — подключение Bitrix24 Вайбкод AI

## Что добавлено

1. Вкладка **«ИИ-помощник»**.
2. Короткая голосовая постановка задачи:
   - запись с микрофона;
   - расшифровка через Bitrix24 Вайбкод;
   - определение существующего проекта, раздела и этапа;
   - определение ответственного, дедлайна и приоритета;
   - ручная проверка перед созданием.
3. Запись встречи РНП:
   - запись автоматически делится на части по 15 минут;
   - части расшифровываются по мере записи;
   - после встречи ИИ выделяет решения и задачи;
   - задачи создаются только после ручного подтверждения.
4. Задачи без этапа по-прежнему отображаются внутри проекта.

## Важно про API-ключ

Ключ Вайбкод нельзя добавлять в `src`, `.env` с префиксом `VITE_` или GitHub.
Он хранится только в секретной переменной Render:

```text
VIBECODE_API_KEY=vibe_api_...
```

## Почему нужен Web Service

Предыдущая версия приложения была статическим сайтом. Статический сайт не может безопасно хранить API-ключ.
Версия 6.2 содержит Node.js-сервер, который:

- скрывает ключ от браузера;
- принимает аудио;
- отправляет его в Bitrix24 Вайбкод;
- возвращает в приложение только расшифровку и черновики задач.

Поэтому в Render нужно создать **Web Service**, а не Static Site.

## Порядок установки

### 1. Загрузить архив в правильный GitHub-репозиторий

Распакуйте архив и загрузите его содержимое в корень репозитория приложения задач.
В корне должны быть:

```text
src/
server.mjs
package.json
render.yaml
index.html
```

### 2. Создать новый Web Service в Render

1. Render → **New** → **Web Service**.
2. Выбрать репозиторий приложения задач.
3. Runtime: **Node**.
4. Build Command:

```text
npm install && npm run build
```

5. Start Command:

```text
npm start
```

### 3. Добавить Environment Variables

Перенесите значения из действующего приложения:

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

Добавьте секретный ключ Вайбкод:

```text
VIBECODE_API_KEY
```

Значение вставьте только в Render. Не присылайте его в чат и не сохраняйте в GitHub.

Модель:

```text
VIBECODE_MODEL=bitrix/bitrixgpt-5.5
```

После первого запуска добавьте адрес нового сервиса для ограничения запросов только вашим приложением:

```text
AI_ALLOWED_ORIGIN=https://ВАШ-СЕРВИС.onrender.com
```

После добавления переменной выполните повторный deploy.

### 4. Запустить Deploy

После успешного запуска откройте:

```text
https://ВАШ-СЕРВИС.onrender.com/api/ai/health
```

Ожидаемый ответ:

```json
{
  "configured": true,
  "model": "bitrix/bitrixgpt-5.5",
  "modelAvailable": true
}
```

### 5. Проверить приложение

В шапке должна быть версия **6.2** и вкладка **«ИИ-помощник»**.

## Тест короткой задачи

Скажите:

> Поставь Тане до пятницы задачу проверить ошибки воронки производства в проекте «Настроена и стабилизирована воронка производства», высокий приоритет.

ИИ должен:

- выбрать существующий проект;
- определить раздел CRM через проект;
- выбрать Таню;
- поставить дату ближайшей пятницы;
- показать черновик;
- создать задачу только после нажатия подтверждения.

## Тест встречи

1. Открыть «ИИ-помощник».
2. Нажать «Начать встречу».
3. Проговорить несколько поручений с ответственными и сроками.
4. Нажать «Завершить запись».
5. Дождаться, пока количество обрабатываемых частей станет 0.
6. Нажать «Выделить решения и задачи».
7. Проверить каждый черновик и подтвердить выбранные задачи.

## Ограничения первой версии

- Для записи необходимо открыть приложение через HTTPS и разрешить микрофон.
- Встреча должна оставаться открытой во вкладке браузера до завершения записи.
- ИИ не создаёт новые проекты, разделы или этапы. Он выбирает только существующие.
- Если ответственный или срок не определены, задача потребует ручного заполнения.
- Для длинных встреч запись делится на части по 15 минут, как рекомендовано для Whisper.
