# MAVIS Task Tracker 6.2.6 — Бэклог как вкладка «Проекты»

Что изменилось:

- Проекты в «Бэклоге» отображаются полноразмерными карточками, как во вкладке «Проекты».
- Внутри проекта видны этапы и все задачи, в том числе задачи без этапа.
- Проект, этапы и задачи можно редактировать прямо из бэклога.
- Можно создавать новый этап и новую задачу внутри backlog-проекта.
- Можно вернуть в работу **одну задачу**, не возвращая весь проект.
- Такая задача получает метку «В работе отдельно» и снова появляется в рабочих задачах, календаре и загрузке команды; сам проект остаётся в бэклоге.
- Эту задачу можно снова вернуть в бэклог отдельной кнопкой.
- Кнопка «Вернуть проект» возвращает весь проект и все его задачи в работу.
- Если целый проект отправляется в бэклог, все его задачи тоже автоматически переводятся в бэклог.
- Новая задача, созданная прямо внутри backlog-проекта, автоматически остаётся в бэклоге.
- Учёт фактического времени при закрытии задачи из 6.2.4 сохранён.

## Обновление

1. В Supabase → SQL Editor выполните `supabase_v6_2_6_backlog_individual_restore.sql` один раз.
2. SQL ничего не удаляет: он только синхронизирует старые задачи внутри уже существующих backlog-проектов.
3. Загрузите содержимое архива версии 6.2.6 в текущий GitHub-репозиторий Mavis Task Tracker.
4. Дождитесь нового Deploy в Render.
5. Обновите страницу с очисткой кэша.

После SQL итоговый запрос должен показать `individually_in_work = 0`. После этого отдельные задачи можно возвращать в работу уже из нового интерфейса.
