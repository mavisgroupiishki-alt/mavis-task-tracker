# MAVIS Task Tracker 6.2.5 — исправление дублей сотрудников

На экране перегруза один сотрудник мог отображаться десятки раз (например, «Саша»), если в локальном кэше или таблице `employees` были повторяющиеся записи одного имени.

Что исправлено:
- сотрудники в интерфейсе всегда дедуплицируются по имени;
- вход по имени также не показывает повторяющиеся записи;
- расчёт загрузки команды считает каждого сотрудника один раз;
- пустой ответственный не создаёт фиктивного сотрудника;
- SQL удаляет дубли из `employees` и ставит уникальный индекс, чтобы они не появились снова.

Порядок:
1. Supabase → SQL Editor → выполнить `supabase_v6_2_5_cleanup_duplicate_employees.sql`.
2. Загрузить содержимое архива версии 6.2.5 в GitHub.
3. Дождаться Render Live и обновить страницу Cmd+Shift+R.

SQL не удаляет задачи и проекты.
