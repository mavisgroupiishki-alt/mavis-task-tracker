# MAVIS Task Tracker 6.2.8 — быстрая расшифровка РНП

## Что изменено

- Готовую запись РНП на 1–2 часа можно загрузить **одним файлом**.
- Сервер автоматически режет аудио/видео на фрагменты по 15 минут через ffmpeg.
- До **3 фрагментов расшифровываются параллельно** вместо последовательной обработки.
- Для сетевых ошибок, 429 и 5xx остаются до 3 повторных попыток.
- Неудавшуюся часть можно повторить отдельно, не перезапуская всю встречу.
- Живая запись РНП тоже делится на 15-минутные части и обрабатывается с параллельностью до 3.
- Лимит файла поднят до 500 МБ.
- Все функции 6.2.6/6.2.7, Бэклог, учёт времени и keep-alive Supabase сохранены.

## Что делать

1. Распаковать ZIP версии 6.2.8.
2. Загрузить **содержимое архива** в текущий GitHub-репозиторий MAVIS Task Tracker с заменой файлов.
3. Сделать commit.
4. Render должен запустить новый deploy автоматически. Если нет — Manual Deploy → Deploy latest commit.
5. Дождаться статуса Live. Первый build может быть чуть дольше обычного, потому что устанавливается `ffmpeg-static`.
6. Открыть приложение и проверить в шапке версию 6.2.8.
7. ИИ-помощник → «Загрузить готовую запись РНП целиком» → выбрать исходный файл.

**SQL для 6.2.8 не нужен.**

## Для двухчасовой встречи

Двухчасовая запись обычно разбивается примерно на 8 фрагментов по 15 минут. Три фрагмента идут на распознавание одновременно, поэтому обработка проходит примерно в три волны, а не 8 последовательных запросов. Реальное время зависит от скорости Bitrix24 Вайбкод.

Во время обработки вкладку браузера лучше не закрывать.
