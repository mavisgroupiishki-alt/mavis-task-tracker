# Обновление: фильтры, разделы и заказчик проекта

## Что добавлено

- Фильтр задач и проектов по конкретной дате, неделе и месяцу.
- Отдельная вкладка «Разделы» для регулярных и операционных задач вне проектов.
- Создание, редактирование и удаление разделов.
- У задачи можно выбрать либо проект/этап, либо раздел.
- В проекте сохранено поле «Ответственный за проект» и добавлено поле «Заказчик проекта».

## Почему текущие данные не исчезнут

Миграция `supabase_sections_filters_update.sql` использует только:

- `ADD COLUMN IF NOT EXISTS`;
- `CREATE TABLE IF NOT EXISTS`;
- создание индексов и политик доступа.

В ней нет `DROP TABLE`, `TRUNCATE`, массового `DELETE` или обновления существующих задач. У старых задач новое поле `section_id` останется пустым, а у старых проектов поле заказчика будет пустым до ручного заполнения.

## Порядок безопасного обновления

1. В текущем дашборде нажать «Резервная копия» и сохранить JSON-файл.
2. В Supabase открыть SQL Editor → New query.
3. Выполнить `supabase_sections_filters_update.sql`.
4. Проверить, что в результате `tasks_preserved` равно текущему количеству задач, а `customer_column_ready` и `section_column_ready` имеют значение `true`.
5. Только после этого заменить код приложения и выполнить Deploy в Render.
6. Обновить страницу и проверить одну тестовую задачу и один тестовый раздел.

Повторный запуск SQL безопасен: используются конструкции `IF NOT EXISTS`.
